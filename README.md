# Minerals Bot v3.2.1 — Author → Critic

Telegram-бот для подготовки и публикации постов о минералах, кристаллах и камнях.

## Главное

- **Автор** пишет содержательный фактический черновик.
- **Критик** читает черновик и источник, проверяет смысл и **концептуально переписывает материал в короткий цельный Telegram-пост**.
- Финальный текст **не режется по символам**. Если результат не проходит проверку, Критик получает его повторно и переписывает короче.
- В финальном тексте нет обязательного старого шаблона с секциями «Характеристики / Где встречается / Интересный факт / Эзотерические свойства». География и факты вплетаются в нормальный текст.
- Раздел **«Применение» запрещён**.
- Эзотерические утверждения сопровождаются оговоркой о том, что это традиционные представления, не научно доказанные свойства.
- Фото и текст отправляются **одним Telegram-сообщением**.
- Автоматически добавляются хештеги и ссылка на канал.

## Pipeline

```text
Минерал + тема + источник
          │
          ▼
┌─────────────────────────┐
│ Автор                   │
│ Groq / Qwen             │
│ Содержательный черновик │
└────────────┬────────────┘
             │
             ▼
┌─────────────────────────┐
│ Критик                  │
│ Mistral                 │
│ Фактчек + концептуальная│
│ редактура               │
└────────────┬────────────┘
             │
             ▼
      Локальная проверка
             │
      ┌──────┴──────┐
      │             │
    OK            FAIL
      │             │
      ▼             └──► повторная редактура
 Фото + caption
      │
      ▼
   Telegram
```

## Формат финального поста

Критик не обязан использовать секционные заголовки. Он получает материал Автора и источник и пишет его заново как короткий нормальный Telegram-пост: название добавляет бот, далее идут 1–3 коротких абзаца с самым интересным содержанием. Если уместна эзотерика, она идёт отдельным коротким абзацем с обязательным disclaimer. Внизу — хештеги и ссылка на канал.

**Не допускается:**

- «💎 Применение» или любые варианты этого раздела;
- механическое обрезание текста;
- незаконченные предложения и многоточия;
- медицинские обещания и гарантированные эффекты;
- служебные комментарии модели;
- дублирование заголовка минерала;
- старый шаблон с обязательными четырьмя секциями.

## Тестовый пост

В боте есть кнопка **🧪 Тестовый пост**. Она выполняет тот же pipeline: Автор → Критик → поиск фото → готовая подпись, но отправляет результат только в приватный чат администратора.

Тестовый режим **не публикует в канал и не помечает минерал как опубликованный**.

## Меню

Постоянная нижняя клавиатура предоставляет:

- 💎 Новый пост
- 🧪 Тестовый пост
- ⏱ Автопостинг
- 📊 Статистика
- ⚙️ Частота
- ▶️ Вкл/Выкл
- 🆔 ID

## Автопостинг

Поддерживается от **1 до 100 постов в сутки**. Интервал рассчитывается автоматически. Частоту можно выбрать кнопкой или ввести произвольное число от 1 до 100. Настройки хранятся в SQLite и не сбрасываются при перезапуске сервиса.

## Конфигурация

Минимум:

```dotenv
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHANNEL_ID=@myminerals
ADMIN_CHAT_ID=
CHANNEL_LINK=https://t.me/myminerals
LOCAL_TZ=Europe/Moscow

GROQ_API_KEY=
GROQ_BASE_URL=https://api.groq.com/openai/v1
GROQ_MODEL=qwen/qwen3.6-27b
MISTRAL_API_KEY=
MISTRAL_BASE_URL=https://api.mistral.ai/v1
MISTRAL_MODEL=mistral-small-latest
LLM_TIMEOUT=90
LLM_MAX_TOKENS=2200
```

Полный шаблон находится в `.env.example`.

## Установка

```bash
python3 -m venv venv
./venv/bin/pip install -r requirements.txt
```

Не коммитьте `.env` и `minerals.db`.

## Systemd

```bash
sudo cp minerals-bot.service /etc/systemd/system/minerals-bot.service
sudo systemctl daemon-reload
sudo systemctl enable --now minerals-bot
```

Сервис использует проектный virtualenv:

```text
/opt/minerals-bot/minerals_project/venv/bin/python
```

## Обновление существующего сервера

Для текущей установки можно обновлять код из Git без замены `.env` и `minerals.db`:

```bash
cd /opt/minerals-bot/minerals_project
cp main.py main.py.backup-$(date +%Y%m%d-%H%M%S)
cp minerals.db minerals.db.backup-$(date +%Y%m%d-%H%M%S) 2>/dev/null || true
systemctl stop minerals-bot
git fetch origin
git reset --hard origin/main
./venv/bin/python -m py_compile main.py
systemctl start minerals-bot
systemctl status minerals-bot --no-pager -l
journalctl -u minerals-bot -f
```

Если Git на сервере не используется, можно заменить только `main.py` и `requirements.txt`, сохранив `.env` и `minerals.db`.

## Диагностика

```bash
systemctl status minerals-bot --no-pager -l
journalctl -u minerals-bot -n 100 --no-pager
journalctl -u minerals-bot -f
./venv/bin/python -m py_compile main.py
```

Полезные сообщения в логе:

```text
author completed: ...
critic completed: ...
preview sent: ...
```

Ошибки `400`, `401`, `429` показывают проблемы конкретного LLM-провайдера. При превышении лимита бот может использовать другой настроенный provider или повторить редактуру.

## Изображения

Изображения ищутся отдельно от текста. Используются Google Images/Custom Search и Wikimedia Commons в зависимости от настроек. Кандидаты скачиваются и проверяются по размеру, разрешению, дубликатам и релевантности.

## База данных

SQLite хранит настройки, список минералов, посты, изображения и состояние автопостинга. Runtime-файл `minerals.db` не должен храниться в Git.

## Безопасность

Никогда не коммитьте:

- `.env`;
- API-ключи;
- Telegram Bot Token;
- `minerals.db`;
- backup-файлы и логи с секретами.
